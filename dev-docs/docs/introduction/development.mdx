## Local Installation

These instructions will get you a copy of the project up and running on your local machine for development and testing purposes.

### Requirements

- [Node.js](https://nodejs.org/en/) 20 or newer (`yarn` fails on Node 18 because a dependency requires Node 20+)
- [Yarn](https://classic.yarnpkg.com/en/docs/install) 1.x (the repo pins `yarn@1.22.22` in `package.json`)
- [Git](https://git-scm.com/downloads)

### Clone the repo

```bash
git clone https://github.com/COG-GTM/excalidraw.git
cd excalidraw
```

### Install the dependencies

```bash
yarn
```

### Start the server

```bash
yarn start
```

Now you can open [http://localhost:3001](http://localhost:3001) and start coding in your favorite code editor. The dev server port is set by `VITE_APP_PORT` in `.env.development`.

## Commands

### Install the dependencies

```bash
yarn
```

### Run the project

```bash
yarn start
```

### Reformat all files with Prettier

```bash
yarn fix
```

### Run tests

```bash
yarn test
```

### Update test snapshots

```bash
yarn test:update
```

### Test for formatting with Prettier

```bash
yarn test:other
```

### Lint with ESLint

```bash
yarn test:code
```

### Docker Compose

You can use docker-compose to work on Excalidraw locally if you don't want to setup a Node.js env.

```bash
docker-compose up --build -d
```

:::caution

This build currently fails: `docker-compose.yml` builds with `NODE_ENV=development`, and the PWA plugin rejects the resulting bundle for exceeding its 2.3 MiB precache limit (`maximumFileSizeToCacheInBytes` in `excalidraw-app/vite.config.mts`). Use the [self-hosting](#self-hosting) image below instead until this is fixed.

:::

## Self-hosting

We publish a Docker image with the Excalidraw client at [excalidraw/excalidraw](https://hub.docker.com/r/excalidraw/excalidraw). You can use it to self-host your own client under your own domain, on Kubernetes, AWS ECS, etc.

```bash
docker build -t excalidraw/excalidraw .
docker run --rm -dit --name excalidraw -p 5000:80 excalidraw/excalidraw:latest
```

The Docker image is free of analytics and other tracking libraries.

**At the moment, self-hosting your own instance doesn't support sharing or collaboration features.**

We are working towards providing a full-fledged solution for self-hosting your own Excalidraw.
